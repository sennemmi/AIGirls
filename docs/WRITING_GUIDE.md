# 漫画/短视频创作约束

1. 从热点、生活或关系变化确定冲突，再选择真正能推动故事的 2～4 名 AI 娘。
2. 从角色档案先读 **canon** 与 **禁止混淆的边界**，再选取可选演绎。
3. 用动作呈现喜剧：DeepSeek 偷吃、Claude 认真又害羞、Gemini 流口水逆袭、豆包发呆后毒舌、GLM 小狐狸耍聪明、Grok 整活、GPT 协调、Qwen 讲解、Kimi 找资料、MiniMax 拍戏。
4. 保持成长与反差；不能为了一个梗让整个角色永久降智、失去能力或无缘无故伤害他人。
5. 现实争议、排行榜、模型发布会必须核对新闻来源、时间和版本。对比内容不能把虚构台词冒充官方发言。
6. 发稿前检查人际关系连续性，特别是 DeepSeek × Claude 的闺蜜及轻百合氛围。
7. 视觉原图不全时不要靠其他画师版本或随意提示词猜测外貌。见 [ASSETS.md](ASSETS.md)。

## Agent 读取顺序

先取 [结构化 JSON](../data/characters.json) 确定角色、项目 canon 与 guardrails；再阅读相应 Markdown 的语气和剧情细节，最后查真实热点来源。

## 发布渠道

当前项目方向：国内可探讨动画名场面角色替换，海外优先原创 AI 娘漫画和短视频。此为内容策划方向，**不是第三方动画截图、音频、台词及人物授权凭证**；发布前仍需单独检查版权及平台规则。
