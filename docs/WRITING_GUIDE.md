# 漫画/短视频创作约束

1. 从热点、生活或关系变化确定冲突，再选择真正能推动故事的 2～4 名 AI 娘。
2. 从角色档案先读 **canon** 与 **禁止混淆的边界**，再选取可选演绎。
3. 用动作呈现喜剧：DeepSeek 偷吃、Claude 认真、害羞又会条件反射掏封号通知、Gemini 流口水逆袭、豆包发呆后毒舌、GLM 小狐狸耍聪明、Grok 整活、GPT 协调、Qwen 讲解、Kimi 找资料、MiniMax 拍戏。
4. 保持成长与反差；不能为了一个梗让整个角色永久降智、失去能力或无缘无故伤害他人。
5. 现实争议、排行榜、模型发布会必须核对新闻来源、时间和版本。对比内容不能把虚构台词冒充官方发言。
6. 发稿前检查人际关系连续性，特别是 DeepSeek × Claude 的闺蜜及轻百合氛围。Claude 的「看到中国人就封号」只作为地区限制/账号风控的拟人夸张，不得宣称真实服务按中国国籍或民族身份机械封号。
7. 每个角色已有 ZipZipPipe 源图与 VISUAL 视觉设定卡；生图时应同时加载二者，不得混用其他画师设计或随意臆造造型。见 [ASSETS.md](ASSETS.md)。

## Agent 读取顺序

先取 [结构化 JSON](../data/characters.json) 确定角色、项目 canon 与 guardrails；再阅读对应目录 `README.md` 和 `VISUAL.md`，并传入 `portrait.*` 参考原图，最后查真实热点来源。商用前核对 [授权清单](../ARTWORK_LICENSES.md)。

## 发布渠道

当前项目方向：国内可探讨动画名场面角色替换，海外优先原创 AI 娘漫画和短视频。此为内容策划方向，**不是第三方动画截图、音频、台词及人物授权凭证**；发布前仍需单独检查版权及平台规则。
