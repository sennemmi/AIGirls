# 人设维护约定

| 类别 | 含义 | 资料处理 |
|---|---|---|
| 原作者资料 | ZipZipPipe 的可核验创作原帖、声明 | 必须保留原帖与许可信息 |
| 社区线索 | 多个创作者使用的梗、互动 | 不能把单一作品当全网共识 |
| 项目 canon | 本仓库正式采用的剧情设定 | 修改需解释连续性，避免角色无故变脸 |
| 可选扩展 | 供编剧发挥的候选想法 | 不得声称是官方或社群定论 |
| 真实事件 | 发布会、测评、争议、厂商声明 | 日期、来源、版本和未决争议缺一不可 |

新增角色时同时维护对应 Markdown 和 data/characters.json。添加图片前先通过 [ASSETS.md](ASSETS.md) 的完整性与授权核查。根目录 MIT LICENSE **不适用于没有获得相应授权的第三方人物画稿**。

推荐新资料记录格式：原始链接、创作者、日期、使用角色、支持什么设定、证据等级、是否有版权限制。
