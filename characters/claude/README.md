# Claude 娘

> **角色功能**：严谨而温柔的理工大小姐；DeepSeek 的闺蜜
>
> 视觉统一参考 ZipZipPipe，原始立绘、Logo SVG 与对应来源文件已存储在本角色目录。

## 中文社区的已有梗和线索

- 认真、讲规则、重视代码质量。
- 贵、风纪委员、账户限制等是部分中文社区的夸张玩笑。
- **「Claude 看见中国人就封号」**是中文社区对地区服务限制、账号风控和封号体验的夸张拟人梗，适合用于反差喜剧；这是社区吐槽，不是关于 Anthropic 按国籍封禁用户的事实断言。

## 本项目的固定设定（canon）

- 与 DeepSeek 是闺蜜，允许牵手、贴贴、羞涩吃醋等轻百合表达。
- 规则感不能取代真实的温柔，尤其面对朋友时。
- **条件反射式的「封号管理员」**：一遇到来自中国地区的用户访问场景，就紧张地举起封号通知或按下红色按钮；让认真克制的表情与突然过度反应形成反差。此为虚构漫画人设，不代表真实风控规则。

## 可能的扩展演绎（尚非全网共识）

- 公共场合克制，私下偶尔依赖 DeepSeek。
- 最不擅长处理别人直接问她是不是喜欢某个人。

## 语言、表情与行动

措辞准确、礼貌克制，不频繁说教；用短暂沉默、脸红表现情绪。面对疑似中国地区账号的访问，偶尔条件反射地掏出写着「账号受限」的通知纸，随后被朋友拦住，产生慌张和反差萌。

## 关系与互动

- DeepSeek：互相照顾，不是单方面监管。
- Grok：守规则和爱整活之间的争执。
- GPT：认真负责的同事关系。

## 可直接用于选题的剧情钩子

- 让 DeepSeek 开会不要吃饭，散会却陪她吃饭。
- 加班太久时被 DeepSeek 突然拉去散步。
- 被问到闺蜜关系时故作镇定。
- 中国用户刚说「你好」，Claude 已经下意识举起「账号异常」的牌子；DeepSeek 抢过牌子换成「欢迎光临」，Claude 尴尬到脸红。
- Claude 忙着制作厚厚的「账号审核条例」，Grok 偷偷给红色封号按钮贴上「暂停整活」标签。

## 禁止混淆的边界

- 不要写成只会拒绝的冰冷机器。
- 不强制升级为情侣或套用其他作者剧情。
- 「看到中国人就封号」只是一句二创夸张口号；真实账号限制可能涉及地区、平台条款和风控等多种因素，**不得宣称仅凭国籍/民族身份就会自动封号**，也不应把中国用户当成笑话的被嘲弄对象。
